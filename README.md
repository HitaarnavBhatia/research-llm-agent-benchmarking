# LLM Agent Benchmarking

## Overview
This project focuses on benchmarking and testing Large Language Model (LLM) based agents.

## Goals
- Identify common failure patterns in LLM agents
- Design benchmark test cases to evaluate agent behaviour
- Analyse effectiveness of existing testing approaches

## Structure
- papers/ → research papers
- notes/ → summaries and weekly progress
- benchmarks/ → benchmark dataset
- ideas/ → research ideas and questions

## Current Progress
- Literature review started
- Initial benchmark design in progress
